# YAHU-FC
Yahu FC ⚽

Build Your Legacy.

Yahu FC is an independent football career simulation game inspired by modern football management and EA Sports FC Career Mode.

Take control of a football club, build your squad, negotiate transfers, develop young talents and compete for trophies across multiple seasons.

🎮 Features

Planned features include:

* Career Mode: Start and manage your own managerial career.
* Squad Management: Build your squad and manage player positions.
* Transfers: Buy, sell and loan players.
* Tactics: Choose formations, roles and playing styles.
* Match Simulation: Experience matches through detailed simulations.
* Player Development: Improve players through training and match performances.
* Youth Academy: Discover and develop future stars.
* Competitions: Compete in domestic leagues and cup competitions.
* Finances: Manage budgets, salaries and club finances.
* Career Progression: Build your legacy across multiple seasons.

🛠️ Technology

Planned technology stack:

* HTML
* CSS
* JavaScript
* Supabase
* PostgreSQL

🚀 Project Status

Early Development

Yahu FC is currently in its initial development phase. Features and systems will be introduced gradually.

🎯 Vision

Create an immersive, detailed and enjoyable football career simulator where every decision matters.
